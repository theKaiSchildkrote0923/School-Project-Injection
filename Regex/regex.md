# Regex

## Metacharacters

| **Characters** | **Description** |
| --- | --- |
| [ ] | [ ] 內字元 |
| \ | 標示 sequence 與特殊字元 |
| . | 所有字元，換行除外 |
| ^ | 由某字元為開頭 |
| $ | 由某字元為結尾 |
| * | 前一個字元出現零次、一次或多次 |
| + | 前一個字元出現一次或多次 |
| ? | 前一個字元出現零次、一次 |
| { } | 前一個字元出現指定次數 |
| \| | 或 |
| () | 群組 |

## Special Sequences

| **Characters** | **Description** |
| --- | --- |
| \A | 開始為某字串 |
| \b | 單字開始或結束為某字串 |
| \B | 單字其中包含某字串，但其開頭或結尾不是 |
| \d | 字串包含 `0-9` |
| \D | 字串不包含 `0-9` |
| \s | 字串包含空格 |
| \S | 字串不包含空格 |
| \w | 字串包含任何字元（`a-z`, `A-Z`, `0-9`, `_`） |
| \W | 字串不包含任何字元（`a-z`, `A-Z`, `0-9`, `_`） |
| \Z | 整個字串結尾為某字串 |

## Sets

| **Characters** | **Description** |
| --- | --- |
| [ ] | [ ] 內字元 |
| \[a-z] | 包含小寫 `a-z` |
| \[^Kai] | 除了 `K`, `a`, `i` 以外的字元 |
| \[123] | 包含 `1`, `2`, `3` |
| \[0-9] | 包含 `0-9` |
| \[0-2][0-6] | `00` 到 `26` |
| \[a-z][A-Z] | 包含小寫 `a-z` 與大寫 `A-Z` |
| \[+] | 字串包含`+`, `*`, `.`, `()`, `$`, `{}`等符號 |
