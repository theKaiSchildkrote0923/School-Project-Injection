#知識卡 #Injection #高二上自主學習 

**Cross-Site Scripting**，簡稱 **XSS**，屬於 Injection 的一種。當網站未妥善處理使用者輸入或其他不可信任的內容，將其解讀為 HTML 或 JavaScript 等可執行內容時，可能造成非預期的程式執行。

主要影響：

- 修改網頁內容或外觀。
    
- 以受害者的身分執行部分網站操作。
    
- 取得瀏覽器中可被存取的敏感資訊。
    
- 導向惡意網站。

## 攻擊分類

依照惡意內容的傳遞方式及執行機制，主要分為：

- **Stored XSS（儲存型）**：惡意內容被儲存在伺服器，例如資料庫，其他使用者瀏覽相關頁面時可能觸發攻擊。
    
- **Reflected XSS（反射型）**：網站將請求中的惡意內容反映至回應，瀏覽器處理回應時可能觸發攻擊。
    
- **DOM-based XSS（DOM 型）**：網頁端 JavaScript 不安全地處理不可信任的內容，並將其放入可能造成程式執行的位置，使瀏覽器產生非預期行為。

## 3. 防禦方式

- **Output Encoding（輸出編碼）**：依照輸出位置，將特殊字元轉換為安全的表示方式。
    
- **Input Validation（輸入驗證）**：確認輸入內容是否符合預期格式。
    
- **Content Security Policy （CSP）**：限制網頁允許載入及執行的資源，降低 XSS 影響。
    
- **Safe DOM APIs**：使用安全的 DOM 操作方式，避免將不可信任內容當成 HTML 或程式碼執行。
